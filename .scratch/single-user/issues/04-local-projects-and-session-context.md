# 04: Local projects and session context

**What to build:** A local user can add a local project/repo, choose which project to work on, create multiple sessions inside the selected project, and have edits/changes happen within the selected project context.

**Blocked by:** 02 Session CRUD without user scoping

**Status:** ready-for-agent

- [ ] Add a local project/repo.
- [ ] Choose the active project.
- [ ] Selected project persists across session creation.
- [ ] Multiple sessions can be created inside the selected project.
- [ ] Edits/changes happen in the selected project context.
- [ ] No multi-user or per-project sharing scoping is introduced.
